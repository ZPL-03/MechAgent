# MechAgent 长周期开发计划书

本计划定义通用 CAE/FEA 多智能体编排平台的能力演进、依赖和验收条件。目标是以一致的数据、工具与评价契约扩展工程场景，并使每项能力拥有可复现的输入、执行记录和验证依据。阶段按证据推进，不以预设日期承诺完成。

## 设计约束

- 编排依赖 `SimulationCapability` 和工具工厂，业务逻辑不围绕测试编号分支。
- 求解器、网格器、CAD 内核和执行器采用各自抽象；专用中间表示、编译器和文件格式由适配器封装。
- 跨 Agent 数据使用 Pydantic 模型；枚举、范围和单位保持单点定义，契约扩展须兼容已有任务。
- LLM 输出接受 schema、范围和能力执行门禁；数值证据来自实际工具或明确引用的参考数据。
- 失败保留阶段位置与已有产物，不通过吞异常、关闭校验或伪造结果满足验收。

## 能力成熟度模型

| 等级 | 所需证据 | 允许描述 |
| --- | --- | --- |
| 研究 | 接口设计、输入样例、风险和实验记录 | 候选方案或实验能力 |
| 可执行 | 真实几何/网格/求解记录、结果提取与失败诊断 | 指定环境和算例可运行 |
| 可验证 | 解析参考、工程基准、网格收敛、跨工具或实验对比 | 指定范围通过验证 |
| 发布 | 自然语言入口、SDK/CLI/Studio、报告、安装、测试与文档一致 | 明确范围内的发布能力 |

单个工具 smoke 不代表平台接入完成；单个算例通过不代表整个物理域通过验证。缺少参考的结果必须保留未验证状态。

## 实现基线

结构线弹性静力提供梁、矩形板、开孔薄板与实体块的闭环。工具工厂内置 `calculix`、`calculix-inp`、`gmsh-occ` 和 `local`；CAD 链路将形体摘要映射为参数候选。Abaqus 的独立本机检查验证外部工具链，生产适配仍需接口与案例门禁。具体实现和边界分别见[架构](architecture.md)、[能力](capabilities.md)与[工具说明](solver_mesh.md)。

## 能力路线

| 阶段 | 目标 | 前置条件 | 进入发布所需证据 |
| --- | --- | --- | --- |
| 结构静力维护 | 稳定输入、诊断、场量与跨后端表达 | 现有数据契约 | 标准算例、自然语言案例、完整安装检查 |
| 几何与网格泛化 | 保留 CAD 拓扑、识别区域、修复诊断、局部尺寸场 | CAD 和网格契约、单位与坐标约定 | 代表零件、拓扑/区域校验、真实网格、质量与收敛 |
| 多后端结构静力 | Abaqus 或其他候选后端的注册适配 | 模型、区域、结果字段可映射 | 同输入对比、位移/应力/反力误差、失败路径与独立安装 |
| 高级结构分析 | 几何非线性、材料非线性、接触、屈曲、模态 | 载荷步、状态变量、接触与求解控制契约 | 工程基准、收敛诊断、路径/特征值对比 |
| 动力学与瞬态 | 时间历程、初始条件、积分与阻尼 | 时变契约和多帧后处理 | 半解析参考、能量检查、步长收敛 |
| 热与多物理场 | 传热、热结构与场映射 | 多场单位、耦合与守恒契约 | 场映射误差、守恒、网格/时间收敛 |
| CFD 与 FSI | 流动、共轭传热、流固耦合 | 流体能力、边界与耦合执行协议 | 公开基准、残差、守恒与网格独立性 |
| 优化与设计探索 | 参数扫描、DOE、代理和不确定性 | 批量任务、设计变量、实验记录 | 基准优化问题、代理误差和独立校核 |
| 平台协作 | 持久队列、远程/HPC、归档与权限 | 作业生命周期、产物索引、身份边界 | 中断恢复、并发隔离、审计与部署验收 |

## 工具生态接入矩阵

| 工具族 | 既有接口或实现 | 候选方向与欠缺 |
| --- | --- | --- |
| 求解 | `AbstractSolver`、CalculiX | Abaqus、Code_Aster、Elmer、FEniCSx、OpenFOAM、SU2；各后端独立满足能力契约 |
| 网格 | `AbstractMesher`、CalculiX INP/Gmsh 路径 | 独立 Gmsh 网格适配、Netgen、重网格和质量统一 |
| CAD | `AbstractCADKernel`、Gmsh OCC 导入 | Abaqus/CAE、FreeCAD、OpenCASCADE；需拓扑保真、单位和区域映射 |
| 执行 | `AbstractJobExecutor`、同步本地执行器 | 异步本地、远程工作站、Slurm、容器；需取消和恢复语义 |
| 后处理 | `PostProcessor` 与 CalculiX 字段解析 | 独立注册 API、ODB、meshio、VTK；需字段位置、坐标和分量约定 |
| 材料 | 内置各向同性材料目录 | 目录/模型注册契约、各向异性、非线性与用户本构 |
| 评价 | 能力 `evaluator` | 收敛、跨工具和实验评价策略；需参考来源与阈值记录 |

候选名称表示技术方向，不表示已安装、已集成、已获许可或已验证。

## 多智能体与 LLM

七个主链路 Agent 负责规划、设计、网格、求解、后处理、分析和报告。GeometryAgent 提供 CAD 候选入口。复杂任务可研究收敛、优化、材料与验证角色，但角色数量由输入输出职责决定。

LLM 评估需同时覆盖能力选择、单位、缺项、歧义、工具约束和错误诊断。结构化输出与建议性审阅分别评价，记录模型与配置，不用语言流畅度替代工程正确性。公开摘要保持脱敏，知识层保持独立依赖方向。

## 里程碑与时间线

| 里程碑 | 完成条件 | 后续依赖 |
| --- | --- | --- |
| 可维护结构静力基线 | 便携门禁、真实求解、双语/主题界面、安装和文档通过 | 几何泛化、多后端实验 |
| 可比较的双后端闭环 | 同一能力可选工具，参考与跨工具证据一致 | 统一场量、网格收敛自动化 |
| 可追溯的复杂分析 | 状态变量、收敛和多帧结果完整 | 瞬态与耦合 |
| 可恢复的平台执行 | 作业持久化、取消、重启恢复和产物校验 | 远程与协作部署 |

各里程碑按依赖和验收结果安排周期。工具实验、界面维护与文档工作可以独立推进；物理域发布受契约和验证前置条件约束。

## 发布与治理

跨层扩展先说明目的、模型契约、工具差异、失败行为与验收数据。发布记录保留版本、配置、工具版本、输入输出与校核结果；完整内容哈希和可恢复归档属于平台化工作。贡献规范见[贡献指南](https://github.com/ZPL-03/MechAgent/blob/main/CONTRIBUTING.md)，执行门禁见[验证说明](validation.md)。

优先处理输入真实性、数值可验证性、CAD 拓扑和执行可靠性，再扩大模型与物理域范围。许可、计算资源、并发控制和私密数据边界按具体后端部署条件评估。
