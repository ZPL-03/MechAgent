# Studio 设计系统

Studio 采用工程软件的分区工作台：模型视口占据主要面积，输入和证据位于两侧。界面使用低饱和表面、清晰分隔、小圆角和有限的状态颜色；主操作、选择与验收信息具有不同视觉职责。

## 设计来源与实现

视觉方案结合 Frontend-Design 与 UI-UX-Pro-Max 的布局和可访问性指导，并在 [Figma](https://www.figma.com/design/lNeVKrRHW9H3Bj0M1gSpdx) 保留界面参考。浏览器实现、语义令牌和实际交互是发布界面的依据，Figma 不承担数值或能力验证。

`theme/tokens.css` 定义排版、间距、圆角和布局，`theme/themes.css` 定义明暗颜色与阴影，`theme/base.css` 定义基础样式。`styles.css` 消费这些令牌，不在组件中复制主题色值。科学场量色标、坐标轴与几何材质承担领域语义，与应用状态色分别管理。

## 颜色与排版

深色以石墨灰背景、分层灰面板、浅灰文本和蓝色主操作组成；浅色使用中性灰画布与白色面板。成功、待复核和失败同时使用文字与颜色表达。实际颜色以 `themes.css` 为唯一数值来源。

界面采用本机 Segoe UI 与 CJK 回退字体；数据代码使用 Cascadia/Consolas 字体栈，无外部字体请求。字号、行高、字重与间距均以 `tokens.css` 为准。表格与数值使用稳定对齐，正文和诊断可换行，产物路径允许断行。

## 布局与控件

| 区域 | 规则 |
| --- | --- |
| 顶栏 | 品牌、执行状态、运行环境、语言和主题控件 |
| 进度条 | 输入、预检、执行和结果的紧凑顺序提示 |
| 输入栏 | 请求编辑、参数补全、预检、运行和案例/历史/模型标签 |
| 主工作区 | 几何/网格/结果视口、任务切换、工程报告 |
| 检查器 | 验收摘要与流程、Agent、产物、JSON 标签 |

桌面宽度不低于 1280px 时采用三栏并在区域内滚动；900–1279px 时检查器位于主工作区下方；不足 900px 时单列排列，顶栏保留有标签的图标操作。布局不要求用户横向滚动整页。

按钮具有可辨认的禁用、悬停和键盘焦点状态。窄屏操作目标至少 44px。Tabs 遵循键盘左右切换与可关联的面板语义。空状态说明下一步操作；错误显示来源与修正方向；运行状态来自后端作业和阶段事件。

## 语言、主题与可访问性

中英文目录位于 `i18n/catalog.ts`，默认中文。语言设置写入 `mechagent.studio.locale`，同步 `<html lang>`。界面语言不自动翻译工程请求、报告或工具返回的自由文本。

主题默认深色，支持深色、浅色与跟随系统，设置写入 `mechagent.studio.theme`。3D 背景和参考网格响应主题变化。禁用本地存储时设置在会话内有效。页面首次绘制前读取主题，减少主题闪烁。

交互保留可见焦点、跳转主工作区链接、控件名称与状态播报。界面尊重 `prefers-reduced-motion`，不以连续动效表达求解进度。语言切换、主题、视口、报告和响应式验证见[验证说明](validation.md)。
